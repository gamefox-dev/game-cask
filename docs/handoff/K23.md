## Mechanism: measured, with explicit uncertainty

Legacy Node synchronous stdin/socket transport can leave Python **blocked in readall despite complete input and
socket half-close**. json.load(sys.stdin) needs the stream end, not merely a complete JSON value.

- Prior independent stalls: scratch-K20/k20d/hang/README.txt and scratch-K22/hang/transport-stall.log:
  Python in TextIOWrapper.read/json.load before compilation, no compiler children/object locks; Node in execFileSync.
- Local legacy 8-thread ×250-call compile probe: worker5 iteration45, 65,536 padding characters,10s timeout.
- Instrumented Node legacy 8×1,000 readall probe: worker3 iteration283, **262,144 bytes**. Python83651 blocked
  _io_FileIO_readall_impl → read; Node31691 in SyncProcessRunner/kevent. UNIX socket inventory found peer
  only in Node (not inherited elsewhere). Both queues empty. Before timeout, Node socket state **0x112** includes
  **CANTSENDMORE (0x10)**; Python state **0x22** includes **CANTRCVMORE (0x20)** (SDK sys/proc_info.h).
  **Shutdown had happened: do not claim Node omitted shutdown.** Python nevertheless slept in read until native
  timeout fully closed the peer, then logged exactly **262,144 bytes**. Start1793754637.297528/end1793754757.1817548.
- Partial write and another process retaining the peer are ruled out **for this reproduction**. Exact
  Node/libuv/macOS EOF/wakeup race remains **unproven**. Earlier bridge question incorrectly described missing
  Node shutdown; corrected in commentary, this handoff and reports/k23/review-evidence-correction.txt.
- Raw incremental os.read8×500 and pure-Python socketpair/sendall/shutdown/readall8×1,000 passed. A clean
  legacy real-build comparison also passed; these do not disprove the intermittent full Node path.
- Deterministic regression supplies all JSON over a socket but deliberately withholds EOF: old helper blocks;
  fixed wrapper returns while peer remains open. This models unavailable EOF, **not** the exact half-close race.
  Regular-file fstat assertion also fails deterministically on the old transport.

## Implemented design

- Central tools/build/exec.mjs stages unchanged input as0600 file/0700 directory, opens read-only,
  **unlinks before spawn**, closes in finally. Compile/lift calls receive anonymous **finite regular-file stdin**.
- Every wrapped build command gets detached Python writer supervision, including outside leases. Python deadline
  covers lease wait/helper/children; Node hard backstop adds2s and group-kills on startup/maxBuffer failure.
  Failure/timeout kills entire group, including TERM-ignoring grandchildren. Existing writer/cache locks and
  external-owner-death drain behavior preserved. Existing cache retries/pruning clean abandoned publication temps.
- Default **30min per invocation**. BGT_BUILD_TIMEOUT_MS or internal timeout must be positive integer
  milliseconds, ≤2147481647; cannot disable. Diagnostics name helper argv, phase, deadline. Local caller edits
  only add phases and preserve diagnostic through build.mjs compile-error wrapping (**K21/K22 merge first**).
- Applies to host-tool/fixture/native compile/link, wasm compile/link, chunk/monolithic lift and wasm-opt.
  Synchronous helper tests migrated; async low-level tests retain explicit pipe lifecycle. parallel.py reads no
  Node config. No compiler/cache-key/codegen changes or success stubs.
- Recovery tests include SIGSTOPped supervisor/hard backstop and descendant cleanup. Documentation:
  [build-cache.md](../build-cache.md#helper-transport-and-deadlines-k23).
