## Mechanism and proof

The actual reproduced failure is **complete input, blocked readall despite socket half-close**.
Python `json.load(sys.stdin)` asks TextIOWrapper/FileIO.readall for the whole stream, not merely one JSON value.
That read depends on the socket EOF/wakeup completing, not merely receipt of a JSON value. This is not a compiler lock wait.

- K20 evidence: `scratch-K20/k20d/hang/README.txt` and samples: native-scale/chunk-test build, Python in
  `TextIOWrapper.read/json.load`, no compiler child or object lock, Node waiting in native execFileSync.
- K22 evidence: `scratch-K22/hang/transport-stall.log` and samples: JSPI scale oracle, same pre-compile state,
  >9 minutes. Those are independent prior observations, not produced by this lane.
- K23 real legacy probe: 8 Node worker threads ×250 calls to old writer/compile with variable padded JSON;
  worker 5, iteration 45, 65,536 padding characters timed out after 10 s. Other workers completed.
- Instrumented legacy readall probe: 8 threads ×1,000 calls; worker 3 iteration 283 stalled with **262,144 bytes**.
  Python PID 83651 in `_io_FileIO_readall_impl → read`; Node PID 31691 waiting in SyncProcessRunner/kevent.
  System-wide UNIX-socket inventory showed the peer endpoint **only in that Node process**, not an inheriting child.
  Kernel socket observations **before** the deadline: both queues empty; Node state **0x112** (connected,
  nonblocking, **CANTSENDMORE**) and Python state **0x22** (connected, **CANTRCVMORE**), decoded from SDK
  `sys/proc_info.h` SOI_S_* constants. This means shutdown had already happened: do **not** call it a missing
  Node shutdown. Python was nevertheless still in blocking read. When the native 120 s timeout fully closed the peer,
  Python returned **exactly 262,144 bytes** (start 1793754637.297528, end 1793754757.1817548).
  Thus **partial input and another process retaining the peer are ruled out for this reproduction**.
- The precise Node/libuv/macOS socket EOF/wakeup race is **not proven**; do not relabel that uncertainty as
  an inherited-fd root cause. An 8×500 raw incremental-read probe passed, as did a subsequent 800-build legacy
  comparison. A pure-Python 8×1,000 socketpair/sendall/shutdown/readall probe also passed; the full Node spawning
  path matters in the observed reproduction, but no particular C-level race is established.
- The committed deterministic retained-peer regression supplies all JSON bytes but deliberately withholds socket
  EOF: old helper blocks; the fixed wrapper uses finite stdin and completes while that peer remains open. This
  deterministic injection models an unavailable EOF, **not** the exact half-close/wakeup race observed on macOS.
  The regular-file assertion also fails deterministically against the old transport.

Raw, ignored evidence: `reports/k23/{stdin-probe,readall-probe,readall-stall,readall-parent,unix-sockets,socket-state}*`;
probe sources in `scratch-K23/{stdin-probe,read-probe,readall-probe}.*`. Raw socket inventories are machine-local,
not committed. Historical PIDs are evidence only, never authority to kill a current process.

## Fix (small shared implementation; local caller annotations)

- `exec.mjs` stages **unchanged input bytes** as a 0600 file in a 0700 directory, opens read-only, unlinks
  before spawn, closes in finally. Every compile/lift caller automatically receives anonymous **regular-file stdin**.
  No helper-specific config pathname, compiler flag, key algorithm or codegen change.
- Writer supervision now also applies outside build leases. Detached group; Python real-time deadline covers
  lease wait and all descendants; Node hard backstop adds 2 s and kills the group on startup/output-buffer failure.
  Python failure/timeout kills the group including TERM-ignoring compiler grandchildren. Existing writer lease
  and object-lock inheritance remain intact; external owner death still drains old writers before new publication.
- Default **30 min/helper**; `BGT_BUILD_TIMEOUT_MS` / internal `timeout` must be positive finite integer
  milliseconds (max 2147481647), cannot disable. Diagnostics include helper argv, phase and deadline. Caller phases:
  host-tool compile/link, fixture compile/link, native compile/link, lift, chunk lift, wasm compile/link, wasm-opt.
  Build error wrapping now preserves this diagnostic rather than replacing it with just “compile failed”.
- Shared input applies to native-scale, generated fixtures, object compile/link, monolithic/chunked lifting and
  wasm-opt. Direct asynchronous low-level helper tests retain their explicit pipe lifecycle; synchronous tests
  now use the canonical wrapper. `parallel.py` reads no Node input and needed no change.
- No assertions, skips or timeouts weakened. Existing atomic-temp retry/pruning owns abandoned compiler temps.
