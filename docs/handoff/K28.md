zero interpreter/stubs/exits/unimplemented GL; exactly eight pipelines; frontend and shared-host accounting,

## Hang budget and load proof

Deadlines **decrease** from 360 s to **60 s tiles / 120 s cross**. Normal slower capture is ~16 s including
startup; 60 s allows roughly 4x that work, and cross owns two such captures. Update exhaustion is independent
of wall time; a pending/hung step is still bounded by Playwright. No retries, dynamic timeout increases or skips.

Artificial load: **24 parallel Node PBKDF2 CPU burners**, 10 CPU host. Five separate Playwright invocations,
all three project/case combinations each time, **15/15 passed, zero timeouts**. Each invocation included fresh
browser launches and normal global setup. The 1-minute system load grew from ~21 to **143** (other builds also ran).

not timeouts. No example/output file was mutated. Temporary specs/routes were removed before the full suite.

no missing tiles or clipping. No text/controls/animation in this static fixture. Screenshots are test attachments;
