## Delivered Q40 contract

- `platforms/win32/w32_glsl.h` now parses scalar opaque sampler `in` parameters, specializes helper calls per
  reflected uniform slot, forwards through helpers, preserves sampler-type and numeric overloads, and removes only
  sampler parameters from specialized signatures. Reflection, locations, texture units and coordinate/swizzle
  canonicalization remain unchanged.
- `bgt/renderers/glsl-opaque.ts` applies the same bounded monomorphization to canonical GLSL used by both the WebGPU
  WGSL frontend and WebGL 2 translator. No sampler value is stored in WGSL function state.
- Generic identity lowering covers all sampler classes requested by decision **#104** (2D, 3D, cube, array,
  shadow, signed and unsigned classes) while existing active-storage capability checks still reject unsupported
  storage truthfully. No cube/other texture ABI expansion was added.
- Rejected `out`/`inout`, sampler returns, arithmetic/assignment, sampler arrays as parameters, dynamic indexing,
  invalid unused-helper calls, scalar sampler indexing and malformed opaque builtin argument shapes fail with logs.
  Constant-indexed uniform-array elements and parenthesized bases are supported.
- Decision **#110** is implemented: WGSL adds a typed zero return only on non-void fallthrough paths, preserving
  defined returns and preceding side effects. `discard` does not terminate WGSL control-flow analysis. The marker is
  `GLSL undefined non-void fallthrough`; WebGL retains native behavior.
- Vertex implicit-LOD texture sampling lowers to level zero; fragment-only texture bias is rejected in vertex code.
- Hygiene regressions cover numeric bindings, local shadowing, local struct members, ordinary inline value structs,
  zero-argument numeric overloads, array parameter constants and prototype/declaration order.
