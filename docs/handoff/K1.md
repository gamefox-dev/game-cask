## Host entropy and scheduler integration

`BGT_CAP_ENTROPY` bit 13 / `bgt_random_bytes` are additive and documented in `bgt/abi/ABI.md`.
Normal play uses Web Crypto, splitting its 65536-byte quota, staging writes and returning bounds/unavailable/I/O
errors. It never falls back to the seeded simulation PRNG. Only the headless differential oracle explicitly injects
a deterministic replay tape; that tape is test-only and not secure randomness. Tests separately use real crypto,
repeat-run differences, >64 KiB, invalid ranges, no provider, immediate failure and late chunk failure without
partial host destination writes. Existing GPU capability tests now assert the precise additional entropy bit;
no assertions were masked or weakened.

AVRT priorities use scheduler weights 1..5, default weight 3; repeated priority calls cannot replenish credits
or starve peers. Native scheduler property tests assert exact 1:5:3 shares, bounded turns and ready/parked exclusions.
No new host scheduling/thread capability or hard realtime behavior is claimed.
