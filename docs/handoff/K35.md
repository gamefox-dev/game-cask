- **Inline low-byte parity** in platforms/x86/x86_lift64.h: builtin parity masked to AL, always inline
  in lifted ALU/shifts; reference unchanged. Actual post-parity VM JSPI wasm has no xs_parity calls/
  definition and343popcnt operators. Removes helper dispatch/loop shape, not all flag production.
- **Boolean whole-block spans** in that header and tools/x86/lift64_guard.h: validate without unused
  host-pointer construction or permission work ONLY behind existing protection-active gating. Full64-bit
  bounds/overflow, nonzero length, <=4096span, both endpoint mappings remain; at most two pages means no
  unchecked middle hole. No host pointer crosses a call/growth/yield. Failed guard uses unchanged generic
  cold replay before local mutation; explicit operand/stack checks remain separate.
