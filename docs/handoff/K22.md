## Implemented design

`tools/build/asyncify.mjs`: whole O2/Asyncify up to32 MiB **code section**; otherwise8 MiB target batches
of whole function bodies. Every shard retains all declarations/imports/globals/types/tables/elements/data.
Nonselected bodies are **analysis-only yield-then-trap placeholders, never published/executed**: conservative
suspension summaries, including indirect edges. Only fixed function-local passes run before AND after
Asyncify; no interprocedural O2/inlining/DCE across placeholders. Exact generated `N_*` exclusions translate
to canonical short per-index identities, avoiding duplicate/missing source-name ambiguity. Profile maps
restore original names. Original suspending wrappers/overrides stay instrumented.

Assembly requires every original body exactly once, unchanged definition indices, identical final function
maps/non-code sections/helper bodies across shards, one shared Asyncify state/helper set, and final V8
validation. >16 MiB individual body or unsupported options/layouts fail explicitly with split/JSPI-only
guidance. Metadata/data and retained output assembly are **not** body-IR bounded. Cache key includes all
wrapper/partition/parser implementations; atomic cache writer leases remain in use.

Build modes: `pipeline.suspensionBuild` or top-level `suspensionBuild`, environment default
`BGT_SUSPENSION_BUILD=asyncify|dual|jspi`. Legacy `jspi` boolean/BGT_JSPI supported. JSPI-only publishes raw
`game.wasm`, marks manifest `suspension: "jspi"`, and **never enters wasm-opt**; missing JSPI or explicit
Asyncify request fails clearly, no imaginary fallback. Selected-artifact integrity failures remain errors.

**Decision #180:** retain global Asyncify default / JSPI opt-in. Reviewer additionally required persistent
per-game preference: implemented top-level **`"suspension": "jspi-preferred"`** in `game.json`, auto-dual
output, manifest `preferredSuspension: "jspi"`, runtime/query override wins, missing API/artifact falls back
to Asyncify. Active variant: existing `diagnostics.suspension` plus `metrics.runtime_profile.suspension`.
No change to BGT wire ABI or renderer-backend-specific policy.
