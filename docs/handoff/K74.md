### Attribution: `memory().gpu.overhead` (new `bgt/runtime/gpu-overhead.ts`)

`{model {engine, api, source, assumed}, canvasBytes, presentationBytes, depthStencilBytes, stagingBytes, totalBytes,
browserBaseBytes}`; `totalBytes` is the new `estimate.components.gpuOverhead` (in `estimate.totalBytes`):

- `canvasBytes` = canvas px x bytes/px + context part − the two RGBA8 copies `canvasBytesEstimate` already counts.
- `presentationBytes`: the renderer's retained full-canvas snapshot (`Renderer.presentationBytes()`), real and
  previously uncounted. WebGL 2 keeps it (its screen LOAD blits the physical image back); WebGPU no longer has one.
- `depthStencilBytes` = materialized depth/stencil bytes x 0.2-0.3.
- `stagingBytes` = once anything was uploaded, max(fixed, k x `native.uploads.largestBytes`) (new executor field: the
  largest single upload call; WebGPU also reports `uploads.chunkBytes`). Chromium WebGL2 max(14 MiB, 2 x L), Chromium
  WebGPU max(32 MiB, 8.5 x L), WebKit 0.
- `browserBaseBytes` (158 MiB Chromium active page, 24 MiB WebKit): a rough estimate, reported, never counted and
  never part of "attributed" (vK74: `bench:footprint` reports it as `gpuProcess.baseEstimateBytes`).
- Engine from the user agent; anything else uses the Chromium factors with `model.assumed: true`.
`bench:footprint` snapshots now carry `gpuProcess {measuredBytes, attributedBytes, baseEstimateBytes, unattributedBytes,
unexplainedBytes}` (attributed = gpuNative + gpuOverhead only) and `jsHeldBytes`.

### Reductions

1. **WebGPU upload bands** (`WebGPUCommands.writeTexture/writeBuffer`): §13 texture uploads go in row bands (whole
   slices when a slice fits) and buffer writes in ranges of at most `uploadChunkBytes` = 1 MiB. Same bytes, same queue
   order. `?uploadchunk=0` / `RuntimeOptions.uploadChunkBytes: Infinity` restores whole writes (A/B).
2. **WebGPU snapshot removed for §13 frames**: a frame without items re-presents the retained logical screen (what the
   last screen frame presented; 2D draws of a screen frame already go into that screen). Saves a canvas-size texture
   and a full-canvas copy per frame. On resize without new frames the image is now rescaled from the logical screen.
3. Not reduced (measured, not avoidable without a contract change): the WebGL 2 snapshot (load-bearing, see above);
   ANGLE's ~14-25 MB staging (bands do not change it); the canvas swap chain (already CSS x DPR, capped); color
   formats (no driver expansion).

## Q138: duplicate JS-held copies

1. **Loader image released after init.** Manifest assets may carry `"release": "after-init"` (ABI §4 "Init-only
   assets", additive). `build.mjs` marks `loader/<module>` (the compacted PE image, read only by the Win32 PE loader
   inside `bgt_init`; guest opens of a module name resolve to the streamed `modules/<module>`). The runtime calls
   `vfs.releaseInitAssets()` once `bgt_init` returns: bytes dropped unless a handle is still open; a later open is
   `E_NOT_FOUND` and listed in `diagnostics().assets.released.reopened` (not `missing`). MMX8: −38.1 MB JS.
2. **One CPU copy per §13 buffer** (`bgt/runtime/shared-buffers.ts`, K71 option (c)). The executor adopts the
   store the decoder allocated at BUFFER_CREATE (`adoptBufferStore`, keyed by the item's `words` array in a WeakMap
   with the owning executor; replays, recordings and cloned items get private copies) and is its only writer, in
   execution order, so every executor read (WebGL 2 index rebasing / wide strides, WebGPU unaligned writes, renames,
   rotated indices, loss restore) keeps execution-time meaning. The decoder runs ahead by the frame's unexecuted
   items and reads `store + journal` (`GpuState.read`: index validation, BUFFER_COPY sources); `host.consume()` calls
   `GpuState.settle()`, which applies journaled writes the sharing executor did not (replay executor, restored
   savestate, dropped frame), so the decoder never depends on the executor. Loss restore re-adopts the same array.
   Accounting: `gpu.native.shadows.bufferBytes` = private copies only, new `sharedBufferBytes`; held once as
   `js.gpuDecoderShadowBytes`. Consistent with `gpu.recoveryShadows` (textures only; buffer bytes stay, once). MMX8:
   −11.9 MB JS.
