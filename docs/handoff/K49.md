## Q85 contract

Rebuild with BGT_DISPATCH_COUNTERS=1 (X86_NATIVE_STATS=1 internally). Default OFF
preprocesses every increment out; no runtime enable branch. Independent of sampled
CPU profiling and guest retirement. native_dispatch reports enabled=0 and null counters/
frames when OFF, never invented zero. No instruction-clock/trace/scheduler/ABI changes.

All cumulative counts are unsigned decimal strings, except bounded peak_depth.
The diagnostic object contains process totals and a 64-entry native-presentation ring,
chronological snapshots with exact present identity and explicit overwrite drops.
Snapshots are taken at the native GDI/SwapBuffers observation, not update returns.
Snapshots work with sampled CPU profiling and retirement disabled too.

- driver_entries counts flat driver invocations, driver_steps counts indirect step calls.
  driver_stops partitions normal flat driver returns, in actual guard order:
  transfer, pending single semantic instruction, block fallback, outer return stop,
  unbounded invocation, missing native registry target. A trap/no-progress abort has no
  normal return event. Nested callback drivers count independently.
- enter/resume/rechain/indirect_attempts count API attempts, including attempts that fault.
  calls/resumes/region_chains retain K32 accepted counts; indirect_hits/misses are site
  lookup results. Rejection histograms name the first completed failed guard (null,
  depth, not_ready, return PC/RSP, registry); faults do not invent a completed rejection.
- native_lookups counts find_native, registry_lookups counts find_lifted; registry results
  partition into forced, positive/negative exact-PC cache hit, binary-search exact/range/
  miss. Admission cache hits/misses are reserved for the measured Q74 follow-up.
- exits counts normal generated register-local region returns by form, guard, quantum,
  interior, call fallback, ret, indirect, other, tail leaf/deferred import, fast-frame
  unwind, region handoff, fast-tail completion. Internal gotos are not returns.
  leaf_continuations counts accepted inline CALL imports that continue in the region;
  they are not exits. memory_fault is a separate checked cold-path attempt; a later
  host trap is not a normal return. Handwritten overrides are not generated region exits.
  Existing sampled census definitions remain unchanged.
