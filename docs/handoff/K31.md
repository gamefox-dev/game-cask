## Contract / usage

Accounting defaults **OFF** (#267/#275): set **BGT_CPU_ACCOUNTING=1** and rebuild.
Disabled hot-path retirement debt/updates and scheduler accounting compile away; metrics and
summaries report **unavailable/null, not zero**. Original CC0 fixtures only; no game files,
web, installs, push, test weakening or compaction.

- Process and stable per-thread u64 retirement distinguish lifted/generic/interpreted instructions.
  Exactly once after successful completion; pre-execution quantum attempts/faults do not retire.
  REP retires once on final completion (including zero-count), not per partial dispatch/iteration.
  No synthetic instructions for native imports/callback scaffolding/handwritten overrides;
  actually dispatched guest callback instructions count. Context restore/reset never roll totals
  back. Guest TSC/RDTSC, traces, scheduling, input and ABI semantics are unchanged.
- Thread id/start address/state include exited identities; no inferred roles/names. Scheduler owns
  active, ready, Sleep/timer, object-wait, I/O, suspended and host-yield host-wall buckets; requested
  and elapsed virtual waits, switches and real host parking are distinct. Parking overlaps state
  buckets. **Active wall is not hardware CPU time**; cpu_time_us stays null.
- Profiling-off retains retirement/metadata, but timing/snapshots are unavailable. Profiling-on
  captures a bounded64 native-present snapshot ring with explicit overwrite drops. Only wholly
  contained consecutive native presents feed exact frame summaries, not after-update TSC deltas.
  Probe JSON includes per-thread/frame instructions and instructions/active-host-wall-second.
- All accounting u64 counters/timestamps are unsigned decimal strings. Bounded id/start address/
  capacity fields remain numbers. BigInt subtraction precedes safe numeric conversion; unsafe
  legacy numeric counts are unavailable. Host-wall strings preserve integer observations of a
  double, not added clock precision. Full schema: [pipeline](../pipeline.md).
