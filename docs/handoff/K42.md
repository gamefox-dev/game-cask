## Approved design / acceptance clarification

Reviewer bridge approved:
1. Asyncify snapshots at consumed suspended-update boundaries; JSPI only at actually returned
   updates. Engine-owned suspended JSPI continuation is not cloneable through JS: explicit
   unsupported-state error, use Asyncify fallback for route search. True suspended JSPI is
   not claimed.
2. GPU command journal from boot including draws/copies/attachments, replay into a fresh
   same-backend renderer, never substitute upload shadows for rendered attachment contents.
3. Explicit test-only deterministic=1 before boot: seeded entropy, update-clocked host time/
   simulated audio, isolated memory storage and scripted input. Earlier assumed normal test
   mode determinism was disproved by source inspection (real performance.now/Web Crypto).
   Reviewer clarified route transfer guarantee is **within deterministic mode**, not arbitrary
   normal wall-clock play. Replay from boot under JSPI in that same mode is required.
4. Opt-in numeric-global/function/table export instrumentation, fresh wasm instances so grown
   memory can roll back. No code/index-space/ABI layout changes.
