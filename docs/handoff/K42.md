## Contract / approved design (reviewer decisions388–397)

- Test-only, explicit deterministic=1 before boot, DEV or VITE_BGT_TEST only. Normal services
  remain unchanged. Seeded entropy, update-clocked guest host time, simulated audio admission,
  isolated memory storage and scripted input. Routes are guaranteed **within deterministic mode**.
- Consumed quiescent update boundary. Full suspended Asyncify state is saved; JSPI only at an
  actually returned update. Engine-owned suspended JSPI cannot be cloned: explicit unsupported
  error, never pretend fallback execution is JSPI. Search with Asyncify and replay from boot in
  deterministic JSPI; that transfer has a browser regression on both backends.
- Sparse linear memory including growth; numeric globals with bitwise float helpers; function
  table identities; guest scheduler/thread/TLS/timer/TSC/PRNG/GL tables in memory; host lifecycle,
  input edges/holds, requests, file cursors/IDs, deterministic services/storage. Fresh wasm instance
  permits growth rollback. Opt-in verified-module instrumentation changes no existing index space
  or ABI. Unsupported engine-owned segment/reference/start state fails closed.
- Ordered native renderer journal, fresh same-backend renderer. Temporary prefix replay materializes
  readback-safe live resources **at residual start**, not suffix end or stale CPU shadows. Keep CPU
  recovery/repacking shadows separately. Physical and WebGPU logical screen contents are captured.
- Packed DS has no portable exact readback. Exact per-mip/aspect constants from initialization and
  full clears are materialized by native aspect clears. Potentially writing draws invalidate by
  immutable depth/stencil masks/ops, as do partial clears, uploads and destination blits. Explicit
  unknown metadata survives file transfer/recompaction. Unknown aspects must reset before any
  residual consumption and before snapshot end, or die unconsumed. Otherwise fail explicitly.
- Restore bounded by live resources + <=2updates/100000 residual commands. Periodic compaction
  every120updates/32MiB; 256MiB estimated history cap fails closed. No unbounded restore replay.
- Host wall-time profiling/log history is not an exact replay oracle. Same artifact/configuration,
  suspension mode, backend and canvas required; no cross-vendor/backend pixel equality promise.
