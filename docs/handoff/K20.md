## Implemented design (requires remaining validation)

- **platforms/win32/w32_gl_names.h**: tables sized by BGT_GPU_LIMIT_HANDLES+1, first word stores actual nonzero
  guest name; internal state holds slots, never arbitrary guest indices. All nine supported namespaces converted:
  textures, buffers, VAOs, FBOs, RBOs, samplers, queries, shaders, programs. Transform-feedback objects/pause
  remain unexposed as before; feedback buffer/query bindings are converted. Shaders/programs generate from a
  shared name space. Bind-created high GLuints supported for textures/buffers/FBOs/RBOs.
- Gen* preflights available slots; on failure leaves output and state unchanged, GL_OUT_OF_MEMORY. Create*
  returns0 on failure. Deleted names may be immediately reused without aliasing retained generations.
- Independent accepted-wire occupancy maps share texture/RBO and buffer/ordinary-uniform pools. Preferred old
  IDs retained when free, otherwise first-free. Texture **1..1023 except900..921 =1001** storage handles;
  buffer **1..1023 except1000..1006/1023 =1015** handles, shared with per-program uniforms. Private texture
  depth900, fallbacks901..905/920..921, sparse-draw images904+slot*2 unchanged; buffers padded1000..1006,
  current attributes1023 unchanged. Existing shader wire allocator already shared compiled/link stages.
- Sampler descriptor cache enlarged128→1023 (guest sampler objects do not map1:1 to immutable descriptors).
  Pipeline descriptor cache remains128, unchanged.
- gl_objects reports per namespace live/peak/failures/failed_requests; every explicit exhaustion logs object
  type, reason, live, failures, failed request count. API wrapper catches other OOM paths (host/GPU byte/submission
  budget) if no explicit diagnostic was emitted. This last wrapper addition has **not yet been tested**.
- Deferred deletion: unbound FBO/VAO references retain old object slot/wire generation; bound containers detach.
  Retired slots collected after APIs, or direct DeleteBuffers in native adapter. Tests still need all edge
  cases/failure atomicity reviewed. Retired objects consume slots until collection, even though no public name.
