## Contract and supported limits

- All nine exposed object namespaces use **1023 slots each**, independent nonzero full-width GLuint guest names:
  textures, buffers, VAOs, FBOs, RBOs, samplers, queries, shaders, programs. Shader/program guest names share one
  name space, with separate slot tables. Bind-created texture/buffer/FBO/RBO names include0xf1234567. Generated
  names may be reused after deletion; bindings and containers retain slots/generations, never arbitrary array indices.
  Deleted objects retained by unbound containers still consume slots/storage until detached.
- ABI unchanged (reviewer#162). Dynamic texture/RBO wire pool: **1001 handles**,1..1023 excluding900..921.
  Historical private depth900, fallback901 and other fallback/sparse-output IDs remain unchanged to avoid needless
  wire churn. Dynamic buffer/ordinary-program-uniform pool: **1015 handles**, excluding1000..1006 and1023.
  Compiled/link-snapshot shader pool1023; immutable sampler descriptor pool1023. A linked two-stage program normally
  needs two additional shader snapshots. Pipeline descriptor cache remains128, not a guest namespace.
- Aggregate GPU reservation defaults to256MiB and is configurable by the existing ABI. Texture bytes, host memory,
  shader/frontend, upload/submission and pipeline limits may fail before names/handles do. TexImage and
  RenderbufferStorage remain **delete-before-create**, avoiding transient double allocation near budget.
- Gen* preflights atomically and leaves output arrays untouched on error; CreateShader/CreateProgram return0.
  Real table, handle, byte-budget or rejected-backend allocation failures raise **GL_OUT_OF_MEMORY** with object
  kind, reason, live count and failed request count. Actual porter metrics expose
  **metrics.gl_objects.<namespace>.{live,peak,failures,failed_requests}**. Reviewer#163 approved the sole non-GL
  production hook in w32_core.c; all state/implementation remains in w32_gl*.
- Rejected retirement generations retain accepted ownership for later cleanup; rejected sampler creation cannot
  produce a draw with sampler0. Delete/rebind, IsBuffer generated-only identity, FBO completeness and retained
  attachment generations have discriminating regressions. Transform-feedback object names/pause remain unexposed,
  as before; existing transform-feedback buffer/query functionality is unchanged.

Implementation details and reservations are also in examples/x64-gl-capacity/README.md and w32_gl_names.h.
No runtime, capability, dependency or ABI change was necessary.
