## Repair

- `tools/build/exec.mjs` stages child argv as an anonymous regular-file descriptor, separately from finite
  regular-file stdin. `writer.py` reads the command plan from fd3, not an argv JSON blob. Existing writer
  leases, inherited lock descriptors, nested process groups, deadlines and fatal tree cleanup remain.
- `command.py` is the shared Python child transport for writer/compile/lift. Large Node script arguments
  use `node-args.mjs`: only the script reconstructs JS argv, after the OS spawn. Compiler drivers get GNU
  response files, not JSON quoting. Large macro sets additionally use a forced-include header: GCC expands
  response files before launching cc1, which otherwise reproduces E2BIG inside the compiler.
- Every supervised child plan checks the portable Linux budget: individual argv/environment strings
  <=131072 bytes including NUL; aggregate <=1MiB with pointer allowance. No large payload environment variables.
  Asyncify retains its complete removelist through file transport, including every translated partition symbol.
  Chunk owner/skip selections use `--select`/`--skip-file`; lift/compile tasks use finite JSON stdin.
- Asyncify cache identity includes transport implementation inputs. Copied-tree fixtures include the new
  helpers. Regressions cover large Unicode/quoted argv, compiler macros, finite stdin, locks, failure cleanup,
  nested supervision, and budget rejection. The lift launch probe enforces Linux's per-string bound on macOS.
- Warning-only edits in the GL adapter/header set and x64 unwind source split misleading statements and
  correct signedness without changing control flow. `check-host-gcc.mjs` covers the actual GL native adapter,
  not just the standalone GLSL parser; x86tool and both allocator widths remain covered.
