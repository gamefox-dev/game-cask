## Implemented bounded scope

- Decoder correctly distinguishes GPR and XMM operands and integer widths for scalar integer conversions,
  including REX.R/B/W; scalar memory widths are retained in decoded operands. MOVD/Q and mask/extract operand
  classes were corrected too. Unsupported MMX conversion encodings fail explicitly instead of being executed
  as scalar SSE.
- Native AMD64 `cvtsi2ss/sd`, `cvt(t)ss2si/sd2si`, `cvtss2sd`, `cvtsd2ss`, `comiss/sd`, `ucomiss/sd`.
  COMI clears OF/SF/AF, sets ZF/PF/CF for unordered, and preserves unrelated EFLAGS bits. Scalar upper lanes
  are preserved. Integer/FP narrowing honors all four guest MXCSR RC modes; integer indefinite is explicit.
  `x86_sse.h` uses integer significand rounding, avoiding int64→double→float double rounding. Both shared
  semantics and native code use these primitives; independent known-answer tests supplement differential tests.
- Added native scalar/packed CMP predicates and SQRT. Fixed scalar conversion/compare memory overreads in
  shared semantics (page-edge tests). FP exception traps, MXCSR status-bit delivery and DAZ/FTZ remain the
  previously documented boundary, NOT newly claimed full SSE exception semantics. Reviewer question timed
  out; its explicit safe default accepted that bounded FP scope and required a spilled thunk trampoline.
- Exact-PC 1024-slot direct-mapped lifted registry cache; registry replacement invalidates it; hits still
  check execute protection and force-interpreter. Includes cached misses/collisions/range-edge tests.
- Native regions return/spill before the ordinary wrapper invokes a thunk via `x86_lift_thunk`. Callback,
  suspension, memory growth and transfer never run with register-local regions live. The real thunk handler
  supplies API metrics, Win64 argument/stack adaptation and last-error behavior; nothing bypasses the profile.
- Same-owner regions/continuations loop in the wrapper without returning to `interp_until`; metrics count
  each logical reentry. The registry still verifies owner and execute permission. Pending generic/quantum
  work and transfer always return to the outer runtime first.
- Native interior entries for **SSE instructions and regions of <=8 instructions**. Suffix guards/counters
  execute before jumping into native code; cold flag recipes exclude skipped prefixes. All other interior
  instruction addresses retain the previous truthful bounded generic fallback.
