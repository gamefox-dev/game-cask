## Design / approvals

- #402: private BGTSTATE v2 binary; async `exportSnapshot` → `ReadableStream` and
  `importSnapshot(stream)`. 16-byte file header, 24-byte record headers, at most 1 MiB raw records,
  bounded 16 MiB metadata sections, raw Uint8/Uint32 blobs, optional per-chunk deflate. Sparse
  pages preserve saved memory length. No whole-file string/buffer/base64; explicit debug JSON
  methods are capped at 8 MiB. No ABI or public save-format change.
- #404: raw ordered test-only mutations with required provenance and owned decoder views; copy
  only reusable legacy vertices. Omit readback observations/completion functions. No JSON/base64
  journal accounting or periodic update compaction. Compact at snapshot time or explicitly via
  `compactJournal` at quiescent boundaries. Estimated 2 GiB journal cap fails closed;
  `journalStats` reports growth. Existing packed depth/stencil proof remains intact.
- Leaf-wise backing-buffer clones avoid Chromium's roughly 2 GiB aggregate structured-clone
  envelope while preserving offsets, aliases, Map/Set identities and cycles. Snapshot and restore
  remain caller-isolated.
- Restore captures caller input synchronously before its first await. `c0e729e` validates
  services/VFS/input/wasm/GPU and exact globals/table counts; stages all fallible clones/accounting
  and completely builds the replacement host/renderer before `testReplace`. Only plain assignments
  follow the swap. Malformed services/globals/memory/GPU and injected mid-build exceptions preserve
  original hash/pixels on both native backends.
- Probe files use bounded 1 MiB base64 Playwright transport and atomic partial-file rename. The
  existing same-page search workflow snapshots once and restores repeatedly; it is documented.
- Scale-fixture correction preserves the buffer-update word until command submission. Compacted
  failed shaders preserve `executeCode`/`completeCode`; unit/browser regressions cover both cases.
