  16-byte header;24-byte record headers; max1MiB raw records, bounded16MiB metadata sections,
  raw Uint8/Uint32 blobs, optional per-chunk deflate. Sparse memory pages retain saved memory length.
  No whole-file buffer/string/base64. Explicit debug JSON methods capped8MiB. No ABI/public save format.
- #404: raw ordered test-only mutations + required provenance, owned decoder views, copy only reusable
  legacy vertices. Omit readback observations/completion functions. No JSON/base64 accounting or periodic

  view offsets/aliases/Map/Set identities and cycles. Snapshot and restore remain caller-isolated.

  exact globals/table counts; stages all fallible clones/accounting and builds replacement host/renderer
  fully before testReplace. Post-swap only plain assignments. Malformed services/globals/memory/GPU and
  injected mid-build exception regressions preserve original hash/pixels on both backends.

  script already supplies long-lived same-page searches: snapshot once, restore repeatedly. Documented.
