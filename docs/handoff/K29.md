## Diagnosis and accepted design

K13 spills/returns native steps before APIs and recognizes thunk-range PCs in the outer driver. It did
not statically identify IAT operands/copied-register provenance: JMP_IND veneers set XE_INDIRECT, fail
local label lookup, and report reason5 before the driver recognizes the profile thunk. CALL_IND also
ends the native region. Zero interpreted instructions never proved zero import boundary/dispatch work.

Reviewer **#240** accepts actual full-width target guards against loader bindings, with:
- call-site execution ONLY for explicitly typed, audited non-suspending leaves, full spill/reload;
- bound outer-driver execution for anything that may suspend/callback/unwind;
- the unchanged dynamic path on a changed operand. A register loaded before a later slot patch still
  calls its old loaded value; guards do not re-read/replace it from the slot.

Reviewer **#242** preserves existing abort-on-memory-fault behavior, NOT new recoverable access-violation
SEH. Explicit RaiseException/unwind must remain non-leaf. Fix shared full-width strlen/strcmp-family
pointers and bounds in BOTH ordinary and leaf execution; test high pointers/protected page edges.
Do not run an in-lane “independent” review. Coordinator/fresh-session validation remains a later gate.

## Implementation retained

- `tools/x86/lift64_imports.h`: conservative forward CFG IAT provenance, MOV/copies, agreeing joins,
  nonvolatile registers across calls; volatile writes/calls and unknown/generic work drop hints.
- `tools/x86/lift64.h`: guarded CALL_IND/JMP_IND. Full 16 GPR/flags/clocks sync for import regions;
  actual operand reads, coverage/continuation/counting retained. Tail veneers can execute leaves without
  a reason5 exit. Native register-local frames never reach the callback-capable bound signature.
- `platforms/x86/x86_rt.c` / `x86_guest.h`: loader bindings, lazy generation-invalidated per-site cache,
  full-width target guard, distinct leaf/bound signatures; bound token consumed BEFORE invocation.
  No per-call allocation. Counters: thunk_dispatches, direct_import_calls, leaf_import_calls.
- Win32 loader binds only profile thunk targets, not imported guest code/data. Thread registry lookup
  cached at binding. Leaf envelope preserves trace/API counts, homes, RAX/return stack/profiling.
- Explicit CRT adapters: malloc/free/calloc/realloc and narrow/wide length/comparison primitives.
  Thread adapters: GetLastError/SetLastError/GetCurrentThreadId/TlsGetValue, current-thread TEB state.
  `w32_thread_leaf_ready` refuses callbacks, transfers, pending waits/yields/deferred results without
  consuming them, so these contexts take the ordinary bound envelope.
- Shared string arithmetic remains 64-bit until checked reads, including full size_t bounded comparisons.
  This fixes silent high-pointer aliasing in both paths, not a strcmp-specific emitter rule.
