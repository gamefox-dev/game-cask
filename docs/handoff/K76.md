# K76 — desktop WebKit collector and memory attribution

Branch `kit/lane/K76`. CC0 fixtures only. Playwright WebKit 2370 and Chromium 1248 on Apple silicon.
Desktop WebKit is informational and is **not iPhone verification**. Scratch evidence: `/Volumes/CaskWork/pi-work/lanes/scratch-K76/`.

| T40 failure | Classification and evidence | Fix and protection |
|---|---|---|
| Collector — explicitly allowed intentional abort | Test assumption: Playwright WebKit emits `Blocked by Web Inspector` for an intercepted `route.abort('aborted')`, not Chromium's `net::ERR_ABORTED`. | Allow and require exactly one occurrence of the browser's exact error for the probe GET. No generic allowlist or skip; the separate unallowed-abort and wrong-allowlist cases still fail in teardown. |
| Collector — real request in flight at navigation | Event-order limitation: WebKit reports `cancelled` before the next document's `request`, `pagehide` and `framenavigated`. Chromium reports no failure for that fetch. A real `AbortController.abort()` also produces `cancelled` on WebKit. | Use `collector.navigateAway(url, request)` for the one known pending request in the WebKit case, and classify its early cancellation only if that navigation commits. Require exactly one navigation-abort log and no request failure there. Chromium uses the original plain `page.goto` path. An abort after a hash-only change still fails; a navigation that never commits also fails. No blanket forgiveness of early cancellations. |
| Q137 — GPU overhead | Test assumption: the runtime already chooses the measured WebKit table; T40 incorrectly required Chromium's model. | Choose expected factors by Playwright's `browserName`, independently of the output under test. Require exact model/source and exact canvas, snapshot, depth, staging, sums and resize deltas before and after resize. No WebKit assertions omitted; no renderer or factor changes. |
