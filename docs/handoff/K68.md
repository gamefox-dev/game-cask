## Q11: build variants from one engineProfile

    "engineProfile": { …, "engineArgs": ["--fixed-fps", "60"], "allowedErrors": [ … ],
      "variants": { "deploy": { "engineArgs": [], "precompress": true, "note": "real-time deploy bundle" } } }

    npm run build:port                       # base only (.engine-private/builds/<id>), prints the defined variants
    npm run build:port -- --variant deploy   # .engine-private/builds/<id>-deploy
    npm run build:port -- --variant all      # base + all variants; also "base,deploy"; npm run engine -- build DIR --variant …

* `framework.mjs`: `validateVariants` (called by `validateConfig`), `selectVariants(cfg, selector)`,
  `resolveVariant(cfg, name)`, `buildEngineVariants(gameDir, cfg, { variants, … })`; `buildEngine(…, { variant })`.
  A variant may override only `engineArgs`, `width`, `height`, `precompress` (+ `note`); identity (runtime, runner,
  pack, hashes), `choice`, `allowUnverifiedRuntime` and `allowedErrors` are shared and refused as overrides. Names
  `[a-z0-9][a-z0-9-]{0,31}`, not `base`/`all`, at most 8; `<id>-<variant>` must be a valid 64-char id.
* Evidence: `resolveEvidence(gameDir, allowedErrors)` (factored out of buildEngine, same vK59 rules) resolves from
  the game.json directory for every variant, so all manifests carry identical `allowedErrors` with `evidenceSha256`.
  The vK59 root restriction (game dir or sibling `../reports`) is unchanged; the unit test records why the old
  `port/deploy/game.json` workaround cannot work.
* Manifest: `variant` (`null` | `{ name, of, overrides, note }`), `variants` (declared names); the effective
  `engineProfile.engineArgs` and the shell identity per bundle. `trial:record` adds `engineVariants`
  (built?, engineArgs, precompressed files, metrics). Schema `profile.schema.json`: `variants`, `precompress`.
* Old single-profile game.json files: unchanged behavior (`selectVariants` -> base only).

## Q12: delivery metrics

* `tools/engine/sizes.mjs`: per file `bytes` / `gzipBytes` (-9) / `brotliBytes` (q11, lgwin 24, size hint) and
  `downloadBrotliBytes`; metrics schema `game-cask/engine-bundle-metrics/2` (additive: also `compression`). Sizes are
  cached in `.engine-private/compress-cache` keyed by SHA-256 + codec parameters + zlib/brotli versions (an entry for
  other bytes or codec versions is ignored). Build line now reads
  `download X MiB (gzip -9 Y MiB, brotli q11 Z MiB)` (**contract change**: `tests/engine/dispatch.spec.ts` regex updated).
* `firstFrameMs` (`tools/engine/perf.mjs`, installed by `installEnginePerf`, also `installEngineFirstFrame`):
  navigation start -> end of the first rAF callback (or task) that issued a draw call into the canvas default
  framebuffer and left a ≤64 px readback that is not a uniform transparent/black/`gl.clearColor` screen. Also
  `firstDrawMs`, `loadStartMs` (runtime wasm request start), `sinceLoadStartMs`, the sample. In `diagnostics()`
  (`firstFrameMs`, `firstFrame`) and probe.json (`firstFrameMs`, `firstFrame`, plus `variant`). Wrappers call the
  originals unchanged and are removed once found; real clock even under `--virtual-time`.
  **Difference from BGT `load_to_first_frame_ms`** (documented in docs/engine-profiles.md): BGT counts from
  `BGTRuntime.load()` to the first completed present whatever it shows; the engine figure counts from navigation
  start and requires non-clear content. `sinceLoadStartMs` / `firstDrawMs` are the closer analogs.
* Optional precompression (cheap, behind options): `precompress: true` (profile or variant) / `--precompress` writes
  `.br`/`.gz` siblings (≥1 KiB, ≥5% smaller; compressed bytes cached and reused only if they decompress to the exact
  input), recorded in `manifest.precompressed`. `npm run engine -- serve DIR --precompressed` /
  `serveEngine(dir, { precompressed: true })` verifies them and serves by Accept-Encoding (br > gzip) with the
  original Content-Type (`application/wasm`: streaming compile kept), `Content-Encoding`, `Vary`. Default serving is
  identity bytes, as before. `capture.mjs`: for an encoded response the decoded body must equal the manifest length
  (unknown length fails) and SHA-256; `encodedLength` recorded.

## Not done / notes

* Brotli q11 for a large pack (hundreds of MB) costs minutes on the first build; it is cached afterwards (per pack
  hash). No opt-out was added; ask if the porter needs one.
* WebGL1 instancing through `ANGLE_instanced_arrays` extension methods and multi-draw extensions are not wrapped by
  the first-frame observer (Godot 3/4 web use the core calls); such frames are seen at their next core draw.
* Godot 4.x runtimes are not cached on this machine: their engine cases skipped (as before); the K68 specs use 3.5.3.

## Review vK68 (PASS) fixes

1. **MEDIUM, stale variants in trial records (fixed).** `variantStatus(cfg, name, base, variant)` (framework.mjs):
   `built` only when the variant manifest matches game.json (variant name/of, effective engineArgs, pack, runner,
   runtime) and the base build (pack, runner, runtime id/sha256 and files, `game.pck`, allowlist evidence hashes);
   else `stale` + `mismatches` (no metrics recorded), `missing`, or `unverified` (no base build). trial-record uses it.

   pack bytes, evidence).

   same lineage; `foo-deploy` (a game) vs `foo` + `deploy`, and `foo-bar` + `baz` vs `foo` + `bar-baz`, are refused
   with the owner named. Unit: 8 cases.
3. **LOW, Accept-Encoding q=0 (fixed).** Weights per RFC 9110: own q, else `*`, else 0; q=0 refuses; highest wins, br
   on a tie; identity fallback (no 406) also under `identity;q=0`. `*, br;q=0` -> gzip. Unit: 7 new cases.
4. **LOW, first-frame observer cost (measured, reduced, documented).** M4 Chromium, 1280x720: draw wrapper ~7 ns per
   call (99.5 vs 106.5 ns); readback 2.4 ms per sample on the GPU, 16 ms on SwiftShader. Sampling is now every

   82 samples, 0.66 ms per drawing frame on average (was 2.15 ms, every frame), ~0.3 ms steady state. probe.json
   `firstFrame.overhead` (`sampleMs`, `maxSampleMs`, `wrappedDrawCalls`), `previousSampleMs`, `skippedDrawFrames`
   (firstFrameMs is an upper bound when frames were skipped). The fixture: content on drawing frame 1, 0 skipped.
5. **LOW, download totals (fixed).** `downloadGzipBytes`/`downloadBrotliBytes` count the compressed size only for files
   that get a sibling (precompressible, >= 1 KiB, >= 5% smaller), raw otherwise; per-file sizes unchanged. Unit
