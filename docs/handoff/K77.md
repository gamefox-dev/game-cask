Caps frame/command/estimated-byte work and refuses unrecoverable provenance without interrupting gameplay. Exact full RGBA8 upload provenance skips GPU reads only until native writes can invalidate it, and only when the recovery shadow represents the same bytes. Restore uses the already compiled instrumented module. Bounded means bounded in history, not a universal latency guarantee for arbitrary live/dense state or hardware.
