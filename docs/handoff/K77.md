## Capture cost

Run `BGT_K77_BENCH=1 BGT_E2E_SCALE_ONLY=1 BGT_WEBGL2_GPU=1 BGT_REQUIRE_WEBGPU=1 npx playwright test tests/e2e/savestate-q112-bench.spec.ts --project=chromium-webgl2 --project=chromium-webgpu` with sample2d built. The CC0 heavy case issues 24 draws per drawing guest update with packed depth/stencil, rotates through sixty 4 MiB uploaded RGBA8 textures, and periodically replaces their pixels. The 291 MB file padding simulates load/hash size, not hundreds of MB of compiled code. Restore checks an entire rotated sample suffix against the original. Baseline is a scratch export of `012b070` with the identical workload and passive timing probes. This reproduces *history-dominated* capture, not the porter’s exact 242.5 s / 1.8 s. No inference about the private game's exact breakdown is warranted.

- First heavy baseline replayed 12,261 frames: WebGL2 GPU replay 20,861 ms, readback/shadows 717 ms, host 202 ms, GPU checkpoint clone 66 ms; WebGPU 7,194 / 141 / 201 / 222 ms. Streamed export (raw in-page drain, no disk) took 3 / 5 ms. Wasm integrity hashing is loader-only, not capture.
- Session-4 heavy run: 12,262 requested host updates plus one step to park at an Asyncify yield (12,263 total). Capture replays 104 frames on both backends. Native readback is 272,445 / 288,829 bytes (WebGL2 / WebGPU) with ~252 MB of live native GPU storage; 75 wasm pages, zero capture-time digests, ~257 MB streamed (baseline ~509 MB). In-memory stream drain 2.75 / 3.11 ms, not disk I/O. Pixel and non-null guest hashes match at every step of a full 60-texture rotation (120 host steps, 60 distinct images) after restore. Lead-in **1,634 → 33,833 ms** (WebGL2) and **1,919 → 10,817 ms** (WebGPU); the test mode moves work into rolling compaction, not out of the system. Ordinary play does not record, compact, or track dirty pages.
- Rolling compaction maintains a detached replay cursor for safe packed cuts instead of re-uploading the previous compact base every roll. Caps frame/command/estimated-byte work and refuses unrecoverable provenance without interrupting gameplay. Exact full RGBA8 upload provenance skips GPU reads only until native writes can invalidate it, and only when the recovery shadow represents the same bytes. Streamed BGTSTATE v3 preserves shared byte views; the reader accepts v2. Other GPU contents are read back; two-update replay and known-constant packed proofs remain unchanged.
- Captures cumulative dirty pages against the initial wasm module image, including zero overwrites, via private memory32 bitmap, guest store/bulk-write barriers, and host write hooks; retains exact scan when multi-memory or an opcode is unavailable. Restore uses the already compiled instrumented module. Bounded means bounded in history, not a universal latency guarantee for arbitrary live/dense state or hardware.
