## Implementation / safety

Reviewer #266 approved bounded, non-suspending generated native calls (maximum32 fast frames), exact-PC
four-target indirect sites and same-owner region loops, with flat guarded fallback. #268 approved weak
cross-chunk N symbols only with **nonnull AND active-registry pointer equality**. Registry rows, F wrappers,
BGT ABI and build-cache schema are unchanged; source/tool/header/compiler-option hashes retain freshness.

A known lifted non-self-recursive CALL emits a real direct N call, pushes the architectural return PC,
publishes all caller-written GPRs/flags/clock/budget, then reloads caller-used/written GPRs after return.
Unused callee writes remain authoritative in X. Resume requires exact continuation PC, RSP above the
post-push floor, correct caller registry identity, no pending generic/import/scheduler/transfer, and the
outer invocation stop. No cached guest pointers survive calls. RET imm, high-pointer faults, quantum
boundaries, deep mutual recursion and full CPU/RAM differential snapshots are exercised.

Suspending imports, callbacks, generic execution, scheduling and nonlocal transfers unwind generated
frames before the outer driver executes them. K29's explicitly non-suspending leaf envelope is retained.
Real generated callers test callback + Asyncify park/rewind + real JSPI + nonlocal guest transfer with
identical interpreted CPU/RAM state and exactly one API execution. The callback sees zero native frames.

Indirect operands/tables are read each time, never folded. Caches store immutable exact-PC registry
results, invalidate on registration generation, and recheck force-interpreter, NX and strict membership
on warm hits. Direct and resume guards also validate the current registry. Conservative AMD64 qword-table
analysis recognizes adjacent constant LEA/MOV bases; segments, addr32, high values, clobbers and unmodelled
implicit/multiple destinations are refused. **No claim to resolve the game's507 sites.**

Region loops remain inside an owner across fallthrough/conditional/backedges, subject to registry and
stop checks. Cross-region branch labels acquire native block entries; this removes otherwise-generic
interior resumptions. Tiny single-region owners have no region-loop check. Direct self-recursion,
**calls to statically self-recursive owners**, and those owners' new exit fast paths stay flat after
measured regression; mutual recursion remains bounded.
