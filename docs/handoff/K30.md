# K30: decode-cache ownership across cooperation points (Q76)

Branch `lane/K30`, base kit dev.17 `c0cf6a6`. Fix commit `3440597`.

## Mechanism (confirmed)
`decode_at` (platforms/x86/x86_rt.c) returned a pointer into the shared 8,192-entry direct-mapped decode cache
(`(eip ^ eip>>13) & 8191`). The interpreter held that pointer across `x86_exec64`, whose quantum check
(`++frame_insns > 2000000`) calls `x86_cooperate()` before the first operand read, and across REP/string iterations
and `x86_lift_block`. The scheduler runs another guest task through a nested `x86_invoke`; that task decodes a
colliding address into the same slot. On resume the first task's `in` points at the other task's instruction.

Evidence: the CC0 fixture runs two guest tasks (task 0 inside the real CRT `c_qsort` with a guest comparator, task 1
running `movss [r8+1c], xmm0; ret` placed at an address that maps to the comparator's slot). On `c0cf6a6` the test
stops with a guest memory access violation at 0x20 (= comparator's R8 (4) + 0x1c): the comparator executed the
worker's SSE store. This is the same instruction shape and failure class as the porter's report. After the fix
the same test passes (one state hash across all configurations).

## Fix
`decode_at` returns `x86_insn_t` by value; interpreter loops (flat AMD64 and i386) and `x86_lift_block` execute
their own copy (~100 bytes per interpreted instruction). Audit: `decode_at` is the only producer of cache pointers;
no static state keeps a `const x86_insn_t*` into the cache (`x86_lift_pending` points at a lifted block's static
predecoded instruction). Native return boundaries (`native_stop/floor/limit`) are saved/restored by `interp_until`
around every nested invocation and read into locals by `x86_run_native`; the fixture asserts they are intact after
each parked callback and that a native continuation never consumes the callback's return marker early.

## Tests
`tests/fixtures/c/decode-cooperation.c` + `tests/unit/decode-cooperation.test.ts` (real decoder, interpreter, CRT
qsort, scheduler context switch; only the instruction clock is placed at a quantum edge). Matrix: comparator quantum
edge at 7 instruction positions x interpreted/lifted entry x Asyncify (+ JSPI when available) with a real host
yield while parked; plus 100-sort aperiodic interleavings (period 1,3,7,13) x interpreted/lifted. All final state
hashes must be identical (lifted vs interpreted differential). Fails on `c0cf6a6`, passes on `3440597`.
