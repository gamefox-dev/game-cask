## JSPI status per #146

**Experimental / opt-in only; no porter/game validation.** Build with **BGT_JSPI=1**, or game configuration
**pipeline.jspi: true** (native BGT: **jspi: true**). Both types are validated. Default **game.wasm** remains
Asyncify; **manifest.variants.jspi** describes verified **game.jspi.wasm**. The JSPI artifact is the same raw linked
wasm without wasm-opt O2/Asyncify, so it can be larger/slower. No alternative guest semantics.

Runtime defaults to Asyncify even if JSPI exists. Explicit **?suspension=jspi** or RuntimeOptions.suspension
selects JSPI only when both WebAssembly.Suspending/promising and the manifest artifact exist; otherwise it selects
Asyncify. Integrity/compile failures are not silently hidden as successful fallback. Only bgt.yield suspends; init,
render and shutdown remain synchronous. Fixed-step callers await the update/yield boundary; overlapping JSPI
updates reject; lifecycle tests cover deep-stack rendering, return, yield-then-return, traps and illegal yields.

Node 24 needs a V8 flag in **Vitest workers**, not just the outer process: **BGT_TEST_JSPI=1** for unit tests;
**BGT_ORACLE_SUSPENSION=jspi** for oracle config. Initial outer-flag-only attempts failed closed with
“JSPI oracle requires JSPI support and artifact”; corrected worker-flag run passes. Chromium exposes JSPI natively.
