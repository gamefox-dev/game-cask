## Continuation 3 — external stale-cache repairs

- **Forced includes / compiler cwd:** compiler-rediscover dependencies for forced includes and imacros on
  every preparation, including cwd-first lookup, rather than recursively inventorying the entire repository.
  Object descriptors carry that same cwd into the Python compiler worker. Adding/removing a cwd shadow changes
  dependencies and keys; removal can safely reuse the original fallback object.
- **Response files:** recursively expand unquoted ASCII response arguments before dependency discovery,
  include-directory extraction, keying **and compilation**. Nested filenames resolve from compiler cwd. This
  also normalizes nested-response support across drivers. Quoting, escapes, other encodings, recursion,
  excessive nesting or unreadable response inputs retain the original argv and **bypass the cache**; no
  approximate tokenizer is allowed to declare a hit.
- **Import:** literal/computed **#import** uses the same shadow-sensitive compiler rediscovery as includes,
  including parent-relative, absolute, comment/digraph/splice forms.
- **Volatile inputs:** discovery now uses actual preprocessing plus a depfile; **-M** alone suppresses the
  date-time diagnostics. **__TIMESTAMP__**, **__DATE__**, **__TIME__** (also token-pasted expansions) bypass
  object caching. Literal/suppression scans fail safe when warnings are disabled. Unsupported preprocessing
  probes fall back to ordinary compiler dependency discovery and also bypass caching. Each bypass gets a
  unique output and explicit reason; the worker refuses hits even when given the same descriptor twice.
  **objects_uncacheable** is included in JSON metrics and the printed build summary.
- **Path builtins:** preserve lexical source/include-path spelling in keys; do not collapse **dir/../**
  components that change **__FILE__** / **__BASE_FILE__** bytes. The existing prefix-map clone-sharing test is
  unchanged and still passes. A header-path regression reproduces the old stale **__FILE__** hit.
- **Regressions:** new **tests/unit/build-cache-inputs.test.ts** covers the four review cases, nested response
  contents/include paths, unsupported quoting, source/header/pasted timestamps, warning suppression,
  source/header path spelling and worker cwd. Cached wasm values are compared with independent fresh
  compiler invocations where the fixture exposes a numeric result. No existing assertions/skips/timeouts
  were changed. The existing CLI long-test budget is used for the full suite, as in continuation 2.
- **Benchmark hygiene:** the standard incremental benchmark now writes a unique runtime-header comment each
  run, restores it byte-exactly, and distinguishes a preexisting fixture from a cold/new fixture. This avoids
  timing hits on an earlier measurement's already-cached comment.

## JSPI remains experimental and opt-in

**No porter/game validation.** Build with **BGT_JSPI=1**, **pipeline.jspi: true** or native **jspi: true**.
Default game.wasm remains Asyncify. manifest.variants.jspi describes verified game.jspi.wasm, copied from the raw
linked module without wasm-opt O2/Asyncify. It may be **larger/slower**; no alternative guest semantics.

Runtime defaults to Asyncify. Explicit **?suspension=jspi** or RuntimeOptions.suspension selects JSPI only with
both WebAssembly.Suspending/promising and the artifact; otherwise Asyncify. Integrity/compile failures are not
silently hidden. Only bgt.yield suspends; init/render/shutdown stay synchronous. Update callers await the yield
boundary; overlapping JSPI updates reject. Yield uses normal import counts/profiling. Deep-stack rendering,
normal return, yield-then-return, traps and illegal yields are tested. Headless JSPI requires stepAsync.

Node 24 requires **BGT_TEST_JSPI=1** for Vitest worker flags; **BGT_ORACLE_SUSPENSION=jspi** supplies the oracle
worker flag. Chromium exposes the real API. All 34 example manifests have both artifacts. Full browser runs
retain their assertions and use BGT_E2E_SUSPENSION=jspi for the second run. Dedicated tests require real JSPI,
park an original deep C stack across 300 boundaries and compare every hello frame across both variants plus
forced-missing-API fallback on WebGL2 and required WebGPU.
