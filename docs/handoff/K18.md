# K18 — fast incremental game builds checkpoint

## Checkpoint

Commit **4dec927526f6ac8674557a8b04861529155661c5** on branch `lane/K18`. This is a stable cache/header checkpoint; the full Tier 1 gate and porter/game validation were not run.

The work is kit-only: no original data, port/game files, GL implementation, translator code, or BGT wire ABI changes were added. Runtime JSPI integration was deliberately not included; see below.

## Delivered

- Object keys and diagnostics in tools/build/objects.mjs: compiler identity, normalized flags, source hash, and compiler-reported transitive dependency/header hashes; negative include-directory inventory changes invalidate discovery; structured miss reasons cover cold, compiler, flags, source, header, eviction and interruption.
- Atomic compile cache reporting in tools/build/compile.py: separate compile-pool/link timings, object decisions, temp-file publication under kernel locks.
- Analysis/lift/C-generation exactness: analysis keys include binary bytes, lifter bytes, identity, base and module name and verify payload hash; generated C/stats markers verify both payloads; x86tool uses dependency-aware objects; lift stats include analysis/C-generation CPU timings.
- Header separation: lifted code reaches x86_guest.h/x86_arch.h without runtime profile or GPU headers; x86.h is the runtime umbrella and runtime units include x86_profile.h explicitly.
- Memory-aware parallelism: tools/build/parallel.py reads the same physical-headroom probe as the heavy gate, reserves headroom, caps workers, and falls back to one worker when unavailable.
- Measurement tooling: npm run bench:incremental records timings, wasm size, resources and cold/no-change/runtime-only cases from the original CC0 scale fixture.

## JSPI decision and probe

Reviewer decision #146 / bridge #147 granted bounded runtime ownership for an opt-in JSPI variant: emit Asyncify and JSPI/no-Asyncify variants; feature-detect JSPI and fall back to Asyncify; test both variants before a game claim.

A minimal suspension-point probe passed in Headless Chromium 156.0.8078.4: WebAssembly.Suspending and WebAssembly.promising were present; two suspension points observed counts [1,2]; the promised export returned 3. Probe sources/runner are local ignored artifacts under reports/k18/jspi-probe.*. This proves Chromium API mechanics only, not game suspension points or production host integration.

No JSPI artifact or host-loader integration is committed. The continuation must keep it opt-in, stay within loader/instantiation plus suspending-import scope, add 300-frame oracle/browser tests for both variants, and retain Asyncify fallback. Asyncify is currently the only shipped pipeline variant.
