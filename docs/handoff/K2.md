### Main implementation

- Real per-page VirtualProtect metadata, previous protection and bounds/allocation validation; VirtualQuery
  reports free/private/image identity and protection regions, retaining original allocation policy. Interpreter,
  lifted operands/block guards and CRT byte-buffer bridges enforce read/write access; execution is checked at
  dispatch. Commit/release allocation bookkeeping replaces the old VirtualFree success stub.
- Shared MinGW FILE/descriptor representation, alias position/lifetime, immediate `_amsg_exit`, formatting,
  secure copies, UTF-16 time output, recursive scheduler-owned CRT locks, `_beginthread`, suspended-wait state,
  priority failures and bounded C scope-handler callbacks. Startup remains ordinary compiled guest CRT code.
- A manifest-derived **build-output-only** VFS index covers shipped assets/streams and process-local file/directory
  updates. Wildcard searches use owned cursor handles, proper end/closed-handle results and FindFirstFileEx layouts.
- Virtual monitor/display/keyboard/Raw Input contracts; process-local clipboard ownership; real pointer hover/leave
  with query/cancel; copied mask/color icon objects and independent GetIconInfo bitmap copies/centered hotspots.
- Census follows the complete ordered runtime table inventory through preprocessing, plus architecture-specific
  scheduler/CRT/data/Win64 precedence. Current registries: **1,001 i386 entries / names; 1,464 AMD64 entries,
  1,388 unique names**. Width-aware GetProcAddress probes cover every listed name and a genuinely missing name.

Cross-ownership edits were necessary in shared x86 memory helpers and `tools/x86/lift64.h` to prevent successful
protection changes being bypassed by generated code. A bridge ownership question timed out after 30 seconds,
selecting its stated default to implement and document those edits. `tools/build/build.mjs` emits the VFS index
because the BGT asset ABI has no enumeration operation; no ABI/runtime web imports were changed. Tiny semantic
harnesses define the added page metadata; all previous assertions remain unchanged.

## Explicit open limits / next integration

- K1's nine new DLLs and other lanes' x87/analyzer/scale requests are not implemented or certified here. No original
  engine/game build, boot or playability claim. No host original executable was run.
- Unavailable features/errors remain as documented, including external processes/physical volumes, async context
  editing, polygon masks, touch, shell launch and zero MIDI devices. Clipboard is local, not browser host clipboard.
- Memory retains the bounded low-address model and legacy RWX loader/heap mappings, not PE section-specific DEP.
  Guard/COW/cache transitions, reserve-only/decommit, general access-violation SEH delivery and self-modifying code
  remain unsupported. Scope-handler tests cover direct callback contracts, not arbitrary MSVC personalities.
- VFS matching is ASCII/case-insensitive and lacks generated DOS short names/full Unicode collation; mutable files
  are process memory only. No persistent kernel write backend. CRT locale/text handling remains bounded.
- TrackMouseEvent is client-only; icon bitmaps must have readable CPU histories. DrawIconEx was not in this group
  and was not added. No physical hardware/mobile fidelity claim.
