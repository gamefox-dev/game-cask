## Implemented behavior

- **WebGL 2 vertex fetch:** active-attribute reflection compares float/signed/unsigned scalar class,
  not vector width. Native vertexAttribPointer/IPointer fills absent components from (0,0,0,1) and
  discards extra supplied components. UNORM8X4 belongs to the float class. Cross-class/signedness
  mismatches still fail. Shared rules live in `bgt/renderers/vertex-input.ts`.
- **WebGPU:** raster fetch already had native fill. Compute-feedback lowering in
  `bgt/renderers/webgpu/feedback.ts` now constructs the shader-shaped value, reads only consumed
  components, and fills typed zeros/one without relaxing feedback-output format/stride rules.
- **Failed lifetime, reviewer #207:** failed native pipeline creation retains the logical handle and
  shader references until DELETE. Known-failed feedback declarations/capture, binds and draws return
  deterministic E_IO plus diagnostics. Rejected bind clears current, so no previous executable is used.
  Delete/reuse works. WebGPU marks its record failed when asynchronous native validation settles;
  callbacks identity-check reused handles. Pending errors remain asynchronous under ABI §13.5, with
  no scheduling redesign. Restore does not recreate known-invalid pipelines; native error scopes
  are balanced even on constructor exceptions and empty validation messages still denote failure.
- GL feedback replacement is transactional: candidate program/VAO allocation/native errors are checked
  before committing or deleting the old executable. Failed setup cleans native state but preserves
  armed capture for the next successful draw. Rejected native binds also clear current.
- `bgt/abi/ABI.md` §13.3/13.5 documents component rules and failed-native/logical-handle distinctions.
  Unknown logical handles remain E_NOT_FOUND; an absent logical draw binding remains E_STATE.

## Exact-width/shape audit

| Guard | Disposition |
|---|---|
| GL vertex-format/native input equality | Fixed to scalar class; native fills/truncates. |
| WebGPU compute-feedback input exact type | Fixed to class plus shader-shaped fetch/fill/truncation. |
| Feedback output type/count/stride | Keep exact: ABI §13.11 explicit byte-record contract, not vertex fetch. |
| Active attribute array/matrix shape | Keep current explicit location-expansion boundary; not scalar/vector fill. |
| Uniform block range | Keep minimum reflected byte-size validation; not exact vector width. |
| Sampler dimension/comparison/integer class | Keep native binding compatibility requirements. |
| Fragment output/target | Already scalar-class checks, not vector-width equality; absent-output masks adapted. |
| GLSL expression/builtin/constructor shapes | Expression typing, not fixed-function fetch; do not broadly relax. |
| Stride/alignment/fetch bounds, attachment shapes | Keep normative ABI bounds/resource rules. |
