## Semantics and query audit

Reviewer #432 approved the existing CPU-shadow guest semantics: guest `glGetError` reads/clears the C first-error latch in `platforms/win32/w32_gl_query.h`; guest `glCheckFramebufferStatus` runs CPU `resolve_fbo` in `w32_gl_fbo.h`. Neither asks the browser driver. Parameter validation, error ordering and completeness mutations remain immediate; native errors are renderer diagnostics/E_IO, not guest GL codes. No ABI/flush import was added.

| Query | Final policy |
|---|---|
| getError | Removed after validated binds, updates, draws and pass boundaries. One production poll follows final presentation/snapshot/readback; debug keeps per-command attribution. Allocation, compile/link, pipeline replacement, requested readback, blit and feedback setup/capture remain correctness boundaries. A bounded-32 pre-dispatch drain attributes stale errors to earlier work; context loss or a non-draining queue rejects deterministically. |
| checkFramebufferStatus | Successful completeness is cached by immutable native texture identity, mip and ordered attachments, never guest IDs; bounded 256 keys, failed checks uncached, debug bypass, restore clears. Growth/new storage changes identity. Native checks remain for mip copies, stencil/depth conversion, requested texture readback and blit. |
| getParameter | MAX_ELEMENT_INDEX/MAX_DRAW_BUFFERS cached at init/restore; other capability/extension queries are startup/restore only. |
| reflection | Uniform locations and block sizes are reflected once per successful native link; handle reuse refreshes reflection. Temporary conversion shaders remain explicit setup work. |
| readPixels/getBufferSubData | Only requested readbacks/savestate surfaces, plus the reviewer #434 generated-transform-feedback wide-stride/sparse-ID packing exception. Upload-owned packing uses CPU shadows. The exception is counted separately as `generatedBufferReadbacks` and needs a future GPU repacking design. |

WebGPU executable behavior is unchanged: no corresponding WebGL synchronous-query cost; existing asynchronous validation, compilation, queue/copy/map readbacks and feedback paths remain.
