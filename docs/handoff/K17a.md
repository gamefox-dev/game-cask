## Contracts

- Generated adjugate/cofactor inverse helpers for float `mat2`/`mat3`/`mat4`, one evaluated value
  argument, no epsilon/pivot threshold/identity fallback. Column-major results include nonsymmetric runtime
  matrices and both multiplication orders. The frontend has no doubles: `double`/`dmat*` remain explicit
  unsupported types, not silently narrowed.
- GLSL leaves inverse of a singular or poorly conditioned matrix undefined. The generated helper always
  executes the same deterministic adjugate/determinant arithmetic schedule; it does not repair or sanitize it.
  Zero determinants naturally lead to undefined nonfinite/indeterminate floating-point values, subject to native
  WGSL float rules. There is **no portable exact NaN payload, signed zero, infinity, or cross-driver singular
  pixel guarantee** in that undefined case. Defined finite inverses are tested numerically.
- Typed `outerProduct`/`matrixCompMult` helpers for every 2..4-column/row shape; correct non-square
  `transpose` result type; native WGSL `determinant` retained.
- Typed bit reinterpretation, packing/unpacking, bit-based `isnan`/`isinf`; `modf`/`frexp` use the
  existing fresh copy-out storage and fixed-index/swizzle machinery. `ldexp` supports scalar/vector exponent
  shapes. Scalar geometric overloads not expressible by WGSL vector-only builtins get value helpers.
- Texture projection, offsets, fetch offsets, LOD offsets and gradient offsets for the existing storage classes;
  project the coordinates/reference, **not the explicit gradients**. Array layers are never projected/offset
  as spatial dimensions. Integer samples use immutable sampler wrap/LOD; shadow advanced sampling compares
  before spatial/mip interpolation. Non-comparison depth lowering preserves integer texel offsets per mip.
- Integer 3D/array textures use existing ABI formats/storage, not new wire types. Renderer reflection and
  pipeline specialization retain integer sample types and proper view dimensions.
- Existing GLSL330 and ES300 WebGL2 paths execute native numeric/matrix functions. Portable later-version
  extras `frexp`/`ldexp` and 4x8 packing have ES helpers; user overloads/prototypes are not duplicated.

translators, not a silent profile/ABI expansion. New renderer cases are exercised directly through the real ABI.
