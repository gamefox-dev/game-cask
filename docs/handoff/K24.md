- Reviewer **#199**: do not wait on unknown game demand or replace the old ceiling with another measured count.

  command layouts and gpu_limits values are unchanged.
- Buffer/VAO guest tables grow atomically from the shared byte-bounded host arena, with full-GLuint hash
  indexes, stable slots, retirement generations and cached live/peak counts. Transient growth is charged too.
  VAOs have **no BGT resource**. No replacement fixed object-count ceiling.

  alignment/offset rewriting, map-pointer migration or CPU reconstruction of feedback output. Private

  scans; reusing a deleted name cannot alias retained slots/generations. Real host/GPU-byte/submission
  failures remain **GL_OUT_OF_MEMORY** plus gl_objects.{live,peak,failures,failed_requests}.
- Reviewer **#204**: only x64-gl-scale has an exact expected-error oracle contract: precisely one deliberate
  BUFFER_CREATE E_LIMIT, counted GL buffer OOM and recovery, and exactly ten recording-only GPU-dependent

  zero command errors; real recovery pixels are mandatory on both native backends.
