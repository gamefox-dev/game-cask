# K14b — fragment outputs, uniform ranges, bounded continuation

Base `3548213` (K12 integration). Kit development only: no game files executed/copied, no captured shader text
in the repository, no web/system installs/dependencies or pushes. All new executable/shader fixtures are original
**CC0-1.0**. No target title/first-pixel/playability claim; the porter must remeasure the unchanged target.

## Decisions / ABI additions

- Q43 reviewer accepted **bounded GPU-only continuation**, not asynchronous renderer draining. §13.12 header flag
  `GPU_CONTINUATION=1` bypasses only the frozen legacy 256-list allowance. The aggregate accumulated frame remains
  bounded by **64 MiB wire bytes / 1,048,576 commands**, including prior/later legacy work. Per-list, upload/transfer,
  resource, vertex and request limits remain. Rejection is atomic E_LIMIT, no dropped work or early request visibility.
- **Q42 reviewer live amendment #107/#108 supersedes the original no-padding/draw-error wording.** The desktop WGL
  GL3.3 context has undefined results for insufficient UBO backing, unlike WebGL's draw-error rule. The accepted
  profile policy draws with the actual available app prefix and a zero-filled tail, counted on every affected
  block/draw as `undersized uniform block range zero-filled`. It logs program/block/name/binding/buffer/offset/size/
  required once per linked program/block/binding. The policy follows the desktop context, **not** shader language:
  GLSL ES300 shaders in WGL use the same policy. Missing/unbound buffers still produce GL_INVALID_OPERATION.
- Reviewer reserved additive **0x64 BUFFER_COPY**, §13.13, and requested GL3.3 glCopyBufferSubData with it. C structs,
  encoders/constants and TS decoder are mirrored, exact layout/encoder tests included; **both** backends implement it.
  Byte-granular copies preserve neighboring native bytes, propagate generated authority, and reject overlap/bounds/
  invalid state truthfully. Each copy charges bounded transfer work against the existing frame upload/transfer budget.

## Delivered paths

### Q41

WebGPU records the actual fragment entry-point's return locations (translated GLSL330/ES300 and native WGSL,
including combined modules) and intersects each immutable target writeMask with them. Vertex outputs and fragment
inputs are never mistaken for fragment outputs. Direct return values, structures, return aliases and literal module
constants are covered. Constant names are case-sensitive/module-scope; nested WGSL comments cannot impersonate entry
points. Unsupported reflection forms fail compilation explicitly, not silent no-output classification.

WebGL2 also needs a native adaptation: its validator rejects active draw buffers missing shader outputs even with
colorMask=0. The backend reflects linked outputs with getFragDataLocation and disables just absent draw buffers;
indexed clears temporarily restore all pass attachments and pipeline changes restore the correct mapping. Ordinary
WebGL2 draws retain their existing pixels. Depth-only/no-color and discarded feedback passes are not dropped.

### Q42

The existing shared C frontend already retains all members of active std140 blocks and computes full 80/176/192-byte
layouts; no captured-layout heuristic or frontend rewrite was needed. Successful draws now bind exactly the linked
block size, not a whole unrelated buffer tail. Per-program block indices/assignments stay separate from context
binding points. Base bindings follow current store sizes after reallocation; range bindings retain offsets/sizes.
BindBufferRange validates full-width arguments, alignment and bounds, and buffer-zero unbind ignores unused range
arguments. A larger non-16-multiple GL range is legal when it covers the complete linked block.

Undersized bound blocks use at most seven reusable private UBOs (7 * 64 KiB ceiling), zeroed then populated with an
**ordered native** prefix copy. GPU-generated prefixes are never read from stale CPU upload shadows; bytes beyond the
app range are never substituted from unrelated app storage. Generated private temporaries are retired after use and
on partial multi-block materialization failures. If wire-budget exhaustion prevents deletion, cleanup is retried
before later source mutation/submission, preserving fail-closed recovery. Failed full BufferSubData uploads do not
change profile shadow/authority; unsuccessful buffer deletion does not forget a live backend buffer.

### Q43

The GL profile flags GPU-only immediate lists as continuations, retaining synchronous command validation and owned
upload snapshots. Legacy screen READBACK stays unflagged. All work still appends to Frame.items in exact order on
both backends. Host.render retains counters for queued update/init work (and no longer spreads a potentially large
item array through JS varargs). Diagnostics lastFrame expose commandCount, continuationSubmits, commandBytes and both
aggregate limits so porters can see headroom. This is a bounded queue policy, not an unlimited engine-scale promise.

## Fixtures / regression strength

- `examples/x64-gl-ranges`: normal -O2 Win64/CRT pipeline, no BGT imports or overrides. Four MRT targets with output
  holes 0/2, exact RGBA written/untouched pixels, mask intersection, empty fragment stage; multiple programs sharing
  points with 80/176/192 layouts, reversed two-block declaration order, reflection offsets, relink, backing resize,
  invalid full-width ranges, aligned nonzero ranges and short/oversized ranges. A GLSL ES300 feedback shader reads an
  actual generated short UBO with sentinel-filled unrelated app tail and requires native prefix + zero missing bytes.
- A single uninterrupted update executes **3000** ordered feedback captures, changing UBO updates and ping-pong native
  dependencies. All 3000 audit words are compared; final sum **11994**, expected byte hash **2a92a441**, plus exact
  final native buffer value. Browser tests assert the >6000-list update and budget diagnostics, not merely no errors.
- GL native copies exercise all nine GL3.3 buffer targets, disjoint same-buffer and generated odd-byte copies,
  exact surrounding bytes and errors. PBO pixel transfers remain explicit unsupported GL errors (never offset-as-client
  pointer interpretation); mapping APIs remain explicit unsupported.
- `gpu-outputs.spec.ts`: both canonical GLSL languages and native combined WGSL, sparse MRT/masks and exact depth-only
  results. Includes case-sensitive constant/local shadow and nested-comment decoy interfaces.
- `gpu-buffer-copy.spec.ts`: **289** full native-buffer comparisons per backend over all source/destination alignments,
  sizes 1..9, disjoint same-buffer copies and odd allocation tails.
- `gl-materialization-failure.spec.ts`: actual compiled profile in GameHost with real native GPU; F9 selects an original
  failure branch. Injects upload, aggregate-wire, and ordinary-uniform-upload exhaustion during two-block
  materialization, requires unchanged feedback output, then a rejected full upload followed by another padded draw,

  injected errors stay local to the diagnostic host; no production error suppression or guest-memory test writes.
- Recording unit/oracle transport deliberately does not execute shaders/rasterize. Its precise known GPU-dependent
  failures are asserted, not represented as rendered-pixel proof. All original raster checks must pass in browsers.
