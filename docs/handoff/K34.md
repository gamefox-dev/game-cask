## Retained changes (independently measured steps)

1. **Full-flag ALU wrapper:** always-inline xl_alu_full permits constant opcode/width/live-mask folding
   through existing xl_alu. No new flag-liveness algorithm; existing precise cold fault recipes retained.
2. **Default checked-pointer path:** default operand/span sites now use the existing always-inline
   same-page mapped/unprotected check. Cold xl_pointer_full retains full-width bounds, cross-page holes,
   permissions and exact replay/partial-store order. No cached pointer crosses calls/growth/yields.
3. **Scalar shifts:** SHL/SAL/SHR/SAR use an always-inline xl_shift with local flags. Rotates keep shared
   x64_shift. Masked counts, zero/oversized counts and the reference's deterministic undefined-flag choices
   are unchanged. This removes X.flags round trips at scalar shift sites without changing spill edges.

Production files: platforms/x86/x86_lift64.h and tools/x86/lift64.h. No dispatch/scheduler/Win32 change.
The rejected scratch-only dirty-register-spill experiment preserved checksum/oracles but measured
11.878/11.090ms versus11.679/11.041ms Asyncify/JSPI; no win, not retained. This is not a promotion claim.
